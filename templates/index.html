How it works

Three simple steps.

1

Upload a photo, or enter the four image features (variance, skewness, curtosis, entropy).

Frequently asked questions

Is it really that accurate?

On the benchmark dataset used here, yes: near-perfect on the held-out test set. That dataset is small and clean, so real-world accuracy will be lower. The Insights page includes a noise test showing how performance drops on messy input.

How does Photo scan work?

The photo is converted to numbers describing print texture, edges, colour and frequency patterns. A model trained on real and fake note photos predicts the result. Until a photo model is trained, the page only shows the image-quality report.

Which currency does it support?

The feature model uses the public UCI Banknote Authentication dataset. The photo model supports whichever currency it was trained on. Fakery is not certified for any currency.

Are my photos stored?

No. Photos are analysed in memory and discarded. Only the result is saved to your history.

Is it free?

Yes. The whole project is built with free and open-source tools.
